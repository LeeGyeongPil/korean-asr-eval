# About the bundled sample

The files in this folder are short sentences written by hand for this project, in the
style of KsponSpeech transcripts (`(spelling)/(pronunciation)` pairs, `b/ n/ o/ l/ u/`
tags, `/ + *` marks). They are **practice data**:

- `ref.trn` is not KsponSpeech text and has no audio.
- `hyp_model-a.tsv`, `hyp_model-b.tsv`, `hyp_model-c.tsv` are **not** output of any real
  speech-recognition model. `model-a/b/c` are imaginary systems built to show how the
  scoring rule moves scores and rankings.
